# P2：结构化输出、诊断报告与终端交互设计

状态：用户已批准；按阶段实施。依赖 P0/P1 共享报告和执行服务；属于 [完整目标](2026-10-15-reliability-roadmap.md)。

## 1. 输出边界

业务命令先返回报告或发出类型化事件，再由文本/JSON/交互展示器渲染。`ui`、`checker`、`appstate` 和客户端选择中的直接打印需要经过输出上下文，不能仅在 main 禁用 banner 就声称支持 JSON。保留已经确认的默认 scan 配色、中文列宽和完整清单。

新增全局 `--json`：有限命令 `check/scan/fix/use/nodes/info/clients/config/history/diagnose` 的 stdout 为单个 UTF-8 JSON 文档。至少有 `schema_version: 1`、`command`、`success`、`data`、`warnings`、`error`、`cancelled`。未知数值为 null，不以 0 或“未知”混入数值字段。节点列表提供完整结果和排名；文本前30名截断不限制 JSON 数据。

`watch --json` 使用 NDJSON，每行一个完整事件，含 schema_version、run_id、递增 sequence、时间、事件类型和 payload；最后发出停止/取消事件。处理错误和早期参数错误也要遵循所选择格式。stdout 无 ANSI、banner、spinner 或普通日志；必要的内部日志进入 stderr。退出码遵循总设计，管道消费者关闭时正常结束，不无限重试输出。

可用性等级、探测状态、倍率/协议/线路标签来源分别存字段，不由消费者从中文标签反向解析。稳定 schema 变更必须提升版本；新增可选字段可保持版本。

## 2. 脱敏诊断

`diagnose` 只读采集：程序/OS/工具构建信息、客户端发现、控制接口类型及状态、系统代理匹配关系、订阅是否托管（可判断时）、组解析情况、恢复日志摘要、依赖完整性、最近错误类别。某模块失败返回部分报告及缺失原因，不因客户端未启动而无法生成整个报告。

单文件 exe 只报告内嵌的构建/依赖清单及构建时校验状态，不声称在用户机器上再次校验不存在的 vendor 静态库。只有源码包实际存在且能读取时，才可额外执行文件哈希检查，并单独标明校验范围。

`diagnose --output <文件>` 保存 JSON 报告，默认不覆盖已有文件；显式 `--overwrite` 才覆盖。输出目录由用户指定或当前目录，不自动上传。诊断默认不批量测速、不访问订阅地址，不自动启用接口，不修改第三方配置。

脱敏采用字段白名单，不输出原始配置/数据库行/响应体。用户目录替换为 `%USERPROFILE%`；节点、组、订阅 ID 和远端 endpoint 使用仅报告内稳定的别名。删除 URL userinfo/query、secret、password、UUID、Cookie、Authorization 等；节点名/错误字符串也可能含订阅地址或秘密，不能原样落入可分享报告。没有显式用户请求时不增加“包含敏感数据”模式。

普通 CLI 的 JSON 是用户本地操作结果，可包含用户正在查看的节点名；可分享 diagnose 报告采用更严格的默认匿名规则。两者必须在帮助中清楚区分。脱敏失败时丢弃该字段并记 warning，而不是回退原文。

## 3. 终端交互

新增 `browse` 入口，要求 stdin/stdout 为终端；重定向或与 `--json` 组合时给出清楚参数错误。实现分页、关键词过滤、协议/倍率/线路标签过滤，保留完整节点名和当前标识。

支持刷新/扫描、选择查看节点详情、选择切换、返回和退出。切换展示客户端、策略组、原节点、目标节点、倍率及验证方式，要求明确确认，默认取消。切换前重新读取内核与组成员关系；刷新后编号与旧列表不一致时不能切错节点。没有唯一目标组时让用户明确选择合法组，不猜测。

复用现有 `info` 的脱敏字段和 P0 切换事务、P1 筛选/评分，不能因交互确认而绕过倍率限制、回滚或客户端身份验证。`--dry-run` 下确认也不发 PUT。Ctrl+C 在菜单中退出，在操作中触发正常取消和事务收尾；终端设置在正常/错误/取消退出后恢复。

采用轻量终端列表与菜单，不引入桌面 GUI 或浏览器服务。交互呈现不会改变 `proxpilot scan` 的非交互默认行为。

## 4. 验收

- 子进程逐条解析所有命令成功、参数错误、API 不可用、验证失败、取消路径的 JSON；完整 stdout 只能有一个文档。
- watch 逐行解析事件，检查序号、最后停止事件、无 ANSI/普通日志；取消可在有界时间结束。
- 注入已知测试 secret、密码、UUID、Cookie、用户路径、恶意节点名及 URL，确认可分享报告中不出现原文；诊断请求记录全为只读。
- 模拟终端输入验证过滤、分页、详情、取消确认、明确确认、失效编号、组变化和 dry-run；确认前绝无节点切换。
- 窄窗口、中文、组合 emoji、无颜色、重定向和管道提前关闭均有回归覆盖。
